# Instrucciones del proyecto

- Leer README.md y docs/estado.md antes de modificar el proyecto.
- Mantener HTML, CSS y JavaScript simples, sin framework salvo decisión acordada.
- Interfaz, mensajes y documentación en español.
- Un módulo por tarea; comprobar sus conexiones con lo existente.
- No presentar las secciones pendientes como funcionales.
- Los datos de negocio usarán archivos JSON importados/exportados. No agregar una base remota sin acuerdo.
- El login es académico, con credenciales en texto. No afirmar que protege la información.
- No agregar credenciales reales de n8n o Google Apps Script a Git.
- Registrar decisiones y actualizar docs/estado.md al finalizar cada módulo, incluyendo comprobaciones y limitaciones.
